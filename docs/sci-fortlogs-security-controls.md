Each approval is bound to the exact control ID, status, statement, and complete binding-ID set. Approval metadata syntax and declared reviewer separation are validated locally; reviewer identity, date, and reference are not externally verified. Human review must confirm them and assess whether each cited line supports its claim.

Green and yellow source notes are preserved as confidence notes, not evidence. Regulations remain collapsed because their source values were not supplied.
