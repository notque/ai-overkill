# Google Go Style Guide attribution

The files listed in `LOAD_ORDER.md` form an unmodified, ordered snapshot of the
[Google Go Style Guide](https://google.github.io/styleguide/go/) at the revision
recorded in `UPSTREAM_REVISION`. Large upstream documents are split into ordered
parts only to satisfy this repository's reference-size limit. Concatenating each
document's parts reproduces the upstream file whose hash appears in `SHA256SUMS`.

upstream changes and updating its pinned revision.
