# Onboarding, flow, pacing, and return

Use this module to audit the arc from arrival through voluntary re-engagement.

## Greedy loading rule

For a focused request, load every packet in this module unless its player moment is demonstrably outside the request. For a complete repository diagnostic, load every listed packet. The packets contain the operational procedure, evidence standard, repair patterns, deliverable rubric, and failure checks.

## Packets

- [game-design-flow-audit](./capabilities/17-game-design-flow-audit.md): audit challenge, skill, focus, feedback, interruption, and recovery.
- [game-design-friction-journey-audit](./capabilities/19-game-design-friction-journey-audit.md): locate effort that does not buy understanding, agency, or value.
- [game-design-ftue-hero-journey-audit](./capabilities/20-game-design-ftue-hero-journey-audit.md): shape first-time play as a short competence-building arc.
- [game-design-goal-density-and-immediacy-audit](./capabilities/21-game-design-goal-density-and-immediacy-audit.md): check whether players can form and renew meaningful intentions.
- [game-design-peak-end-audit](./capabilities/35-game-design-peak-end-audit.md): shape memorable highs and endings without manipulative pressure.
- [game-design-zeigarnik-effect-audit](./capabilities/55-game-design-zeigarnik-effect-audit.md): use unfinished goals as voluntary anticipation with transparent control.

## Cross-domain checks

When a finding changes the player path, also load the adjacent module for fairness, pacing, player context, social impact, economy, and delivery feasibility. Do not treat this index as a substitute for the packets.
