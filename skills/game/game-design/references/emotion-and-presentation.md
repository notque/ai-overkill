# Emotion, mood, and presentation direction

Use this module when game feel must be translated into art, audio, motion, interface, and content choices.

## Greedy loading rule

For a focused request, load every packet in this module unless its player moment is demonstrably outside the request. For a complete repository diagnostic, load every listed packet. The packets contain the operational procedure, evidence standard, repair patterns, deliverable rubric, and failure checks.

## Packets

- [emotional-canvas-moodboard](./capabilities/02-emotional-canvas-moodboard.md): translate a target feeling into interaction and presentation direction.
- [game-design-emotional-canvas](./capabilities/11-game-design-emotional-canvas.md): specify intended feeling through playable cues.
- [moodboard-generator](./capabilities/60-moodboard-generator.md): assemble a legal, purposeful reference board that translates into production choices.

## Cross-domain checks

When a finding changes the player path, also load the adjacent module for fairness, pacing, player context, social impact, economy, and delivery feasibility. Do not treat this index as a substitute for the packets.
