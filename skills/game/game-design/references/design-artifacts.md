# Design artifacts and communication

Choose the artifact that resolves the decision, not the prettiest document.

| Artifact | Must answer |
|---|---|
| Prototype brief | Which unknown, test, observation, decision, and stop rule? |
| One-page design document | Player promise, loop, pillars, audience, progress, risks, scope, next test. |
| Emotional canvas | Target feeling, contrast, sensory cue, interaction, rejection criterion. |
| Moodboard | Licensed references, intended signal, exclusions, production translation. |
| Pitch deck | Player, promise, evidence, market context, differentiation, plan, ask. |
| Craft critique | Learning, pattern discovery, feedback, mastery arc, novelty renewal. |

Use low-fidelity artifacts first. A moodboard cannot substitute for an art brief,
and a document cannot substitute for a player observation. When producing a
renderable artifact, use approved local tools and owned or licensed assets. Do
not download arbitrary material, install dependencies automatically, or claim a
reference grants reuse rights.
