# emotional-canvas-moodboard

## Purpose

Translate a target feeling into interaction and presentation direction. This packet is a repository-aware operating procedure, not a label to apply to a design.

## Evidence intake

Inspect repository evidence before requesting context: art brief, UI, animation, audio, copy, licensed reference board. Then inspect these capability-specific signals: emotional target, contrasting feeling, sensory signal, interaction rhythm, reference risk. Ask only for external evidence, confidential player research, decision authority, or constraints unavailable in the repository.

Mark every claim as `observed`, `documented`, `measured`, or `inferred`. Give each inference a confidence level and a disproof route.

## Method

1. Normalize target feeling, three descriptors, adjacent and contrasting feelings, sensory references, and no-go signals.
2. Create 6–12 visual search lanes: shape, color/light, environment, material, composition, motion, interface, and period anchors.
3. Curate a candidate pool before selecting 6–12 images; every kept image must have a distinct board job.

## Diagnostic questions

- What exact player moment or delivery decision is under review?
- Which capability lens above has the strongest evidence and which is only an inference?
- Which competing explanation would produce the same visible symptom?
- What is the smallest change or test that would separate them?

## Output schema

Return all of the following, not a generic summary:

- emotional canvas
- search plan
- candidate/keep/reject ledger
- licensed/owned asset status
- board brief with atmosphere and readability variants

## Failure modes

- A collection of related images is not a moodboard.
- Do not treat reference discovery as permission to reuse assets.
- Aesthetic taste is never treated as player evidence.

## Example application

When a team needs to translate a target feeling into interaction and presentation direction, begin with the available build path and the capability matrix above. Apply the named method to the affected moment, not an abstract feature description. If direct player evidence is absent, publish an evidence gap rather than a false conclusion; label the result as inferred and use the validation below to move it toward measured evidence.

## Decision procedure

1. Use `emotional target` as the first discriminating lens, because it is closest to the stated capability.
2. Compare it against `reference risk` before selecting a fix; this prevents a single-dimension conclusion.
3. Convert the result into `emotion canvas and production brief` with an owner, a quality guard, and a stop rule.

## Validation

Ask reviewers to identify the target feeling and intended readable play space from the board alone.

## Full-diagnostic disposition

In a complete repository diagnostic, run this packet and record `assessed`, `evidence gap`, or `not applicable` with a game-specific reason. A missing artifact is a finding; it never permits silent omission.
