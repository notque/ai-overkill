# Creative direction, novelty, and options

Use this module to widen a constrained decision without losing the player promise or production reality.

## Greedy loading rule

For a focused request, load every packet in this module unless its player moment is demonstrably outside the request. For a complete repository diagnostic, load every listed packet. The packets contain the operational procedure, evidence standard, repair patterns, deliverable rubric, and failure checks.

## Packets

- [game-design-brainstorm-methods](./capabilities/06-game-design-brainstorm-methods.md): choose an ideation method that changes the decision.
- [game-design-creative-unblocker](./capabilities/09-game-design-creative-unblocker.md): turn a stalled design decision into a bounded next experiment.
- [game-design-five-options](./capabilities/16-game-design-five-options.md): generate genuinely different paths before choosing.
- [game-design-grow-design](./capabilities/24-game-design-grow-design.md): use goal, reality, options, and commitment to move a decision forward.
- [game-design-novelty-spectrum-audit](./capabilities/31-game-design-novelty-spectrum-audit.md): place novelty where players can learn it and value it.
- [game-design-one-thing-to-remove](./capabilities/33-game-design-one-thing-to-remove.md): find the highest-leverage subtraction.
- [game-design-option-generation](./capabilities/34-game-design-option-generation.md): generate options across goals, information, pressure, consequence, and scope.
- [game-design-roadblock-reframing](./capabilities/48-game-design-roadblock-reframing.md): convert a blocked statement into a controllable question.
- [game-design-transformative-reuse](./capabilities/53-game-design-transformative-reuse.md): borrow a familiar pattern only after changing its player purpose.

## Cross-domain checks

When a finding changes the player path, also load the adjacent module for fairness, pacing, player context, social impact, economy, and delivery feasibility. Do not treat this index as a substitute for the packets.
