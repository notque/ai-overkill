# Cognitive and behavioral lenses

Use these as hypotheses about a moment, never as diagnoses of a person or a
license to manufacture compulsion. Confirm them with playtest behavior.

| Lens | Inspect | Safe response |
|---|---|---|
| Fast and slow choice | Is urgency appropriate to consequence? | Match cue, time, and reversibility to stakes. |
| Behavior prompt | Do ability, opportunity, and a clear prompt coincide? | Remove a barrier; do not add pressure. |
| Attribution | Does a loss look like skill, system, luck, or another player? | Explain cause and restore agency. |
| Perceived randomness | Can players estimate range, influence, and recovery? | Reveal signal, narrow variance, or add counterplay. |
| Open goal | Is unfinished business anticipation or anxiety? | Offer meaningful return without absence penalty. |
| Personality/archetype | What preference could this moment serve? | Test hypotheses; do not segment by labels alone. |

For each audit, write: expectation, cue, choice, system result,
interpretation, and next action. Change the smallest cue, rule, or recovery
path that could disprove the hypothesis. Never optimize a behavioral lens
against informed choice, player welfare, or accessibility.
