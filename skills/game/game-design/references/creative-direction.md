# Creative direction and option design

Use for design pillars, creative blocks, novelty, reuse, backcasting, and
feature choice. Begin with the player promise, not an implementation idea.

| Need | Ask | Produce |
|---|---|---|
| Pillars | What must this game never stop feeling like? | Three to five trade-off rules |
| Novelty | What is familiar, what is new, and where is learning paid? | Novelty placement plan |
| Reuse | What existing pattern is borrowed, and what player need changes it? | Transformative delta |
| Block | What decision is blocked, by whom, and what would make it safe? | Constraint-based next step |
| Options | What cannot change, and which outcome matters most? | Five distinct options, including a cut |

Generate by changing one design axis at a time: goal, verb, information,
pressure, consequence, social relation, fantasy, or progression. Reject options
that merely rename the same mechanic. For each viable option, name the player
moment, pillar fit, cost, uncertainty, failure mode, and cheapest test.

Backcast from an observable ideal player story: what did they choose, learn,
feel, and tell another player? Trace prerequisites backwards until the next
prototype is clear. For a red-team review, test dominant strategy, unreadable
choice, content exhaustion, exploit, accessibility failure, economy pressure,
and production risk.
